# Положить элемент на полку

Репозиторий: `C:\Claude\Portfolio v2\Projects\shelf` (GitHub `kloserock97-tech/shelf`, сайт https://kloserock97-tech.github.io/shelf/).
Устройство и правила — `docs/spec.md`, схема полей — `src/content.config.ts`.

## 1. Понять, что и откуда

- Найди источник: файлы, откуда элемент берётся, и что ему нужно (зависимости, ассеты, данные).
- Определи происхождение. Своё — `origin: own`. Переписано по мотивам известного приёма — `adapted` с `priorArt`.
  Чужой код, константы, ассеты — не публиковать как есть: переписать или положить в `private/` с `origin: third-party`.
  `npm run check` сам ловит отпечатки известного чужого кода (хэши Хоскинса и Килеса, MurmurHash, lowbias32,
  mulberry32, `fract(sin(…))`, IGN, FXAA, CAS, AgX, Khronos Neutral, Shadertoy-классику, GSAP, LYGIA —
  `scripts/lib/provenance.mjs`). Замены бери свои: хэш, случайные числа и дизер — из `items/hash-kit`, сглаживание
  краёв — из `items/edge-aa`, звуки — синтезатор `items/sound-button/variants/synth`. Ассеты — только свои: рендер
  Blender, процедурная геометрия, свой синтез.
  Опись с пометками происхождения — `docs/research/inventory.md`.
- Выбери тип и короткий kebab-case slug. Типы по группам сайдбара:
  Interface — button, control (переключатели, поля, ползунки), card, navigation, gallery;
  Animation — scroll, cursor, text, transition, loader;
  Graphics — webgl, shader, object, background, icon;
  Pages & tools — section, sound, utility.
  Тип называет, что внутри. Общих корзин вроде «компоненты» или «анимации» нет: всё на полке — компоненты.
  Нужного типа нет — добавь его в `src/lib/taxonomy.ts` (подписи EN/RU, иконка Lucide, группа, строка о типе) и в
  `scripts/lib/items.mjs`.

## 2. Собрать папку

- `npm run new -- <slug> --type <type> --title "<Title>"` создаёт `items/<slug>/`; для приватного добавь `--private`.
- `variants/<id>/` — чистый код без привязки к проекту: убрать импорты модулей проекта, тексты кейсов, скриншоты
  продуктов под NDA, адреса закрытых систем, личные данные. Самодостаточность важнее полноты.
- Варианты: основной — тот, на котором элемент написан. React-вариант (`react/*.tsx`) добавляй, если элемент —
  компонент интерфейса; он же попадёт в реестр shadcn, если в `item.md` указан `registry: <slug>`.
- `demo/index.html` — живое превью: прозрачный фон, элемент по центру, файлы варианта подключены через
  `../variants/<id>/…`. Для больших проектов с собственной страницей вместо демо — `demo.url`.
- `item.md`: `title` — по-английски (он же имя в обоих языках интерфейса); `summary` — одно-два предложения, что это и как
  себя ведёт; `tech`, `tags` (добавь русские синонимы для поиска), `added` — сегодняшняя дата, `source` — проект и путь.
  В теле — заметки по-русски: как устроено, числа, доступность, грабли, флаги демо. Коротко.
- **Тексты сухие** (просьба Никиты 29.09). Описание и заметки говорят, что это и как работает, — и только. Не пишем,
  зачем элемент добавлен, что он «своё вместо чужого», откуда пришла идея, про лицензии, версии и «на сайте было
  иначе». Происхождение живёт только в полях `origin`, `source` и `priorArt`; на странице видно лишь `source` как
  «Источник», `priorArt` не показывается.

## 3. Превью

- `npm run capture -- <slug>` — постер 4:3 в Chrome с GPU (для WebGL проверь, что в выводе ANGLE, а не SwiftShader).
  Локальное демо съёмщик отдаёт через временный http-сервер, так что ES-модули работают; параметры демо —
  `--query "?p=0.4&play=0"`. Мелкий элемент снимай с `--size 640x480`, сцену — с `--wait 7000`.
- Если у проекта уже есть кадр или ролик (например, `Portfolio 3D TS2/public/ui/card-*.webp|mp4`), можно взять его:
  `poster.webp`, `loop.mp4`.

## 4. Проверить и опубликовать

- `npm run check`, затем `npm run build` и `npm run preview` + `npm run smoke`.
- Посмотри страницу элемента в светлой и тёмной теме: демо живое, код переключается, заметки читаются.
- Коммит — только свои файлы поимённо (`git add items/<slug> …`), никакого `git add -A`.
- Пуш в `main` без `gh`: токен в переменной `GITHUB_PERSONAL_ACCESS_TOKEN`, передавать через `GIT_CONFIG_*`
  (`http.https://github.com/.extraheader`), в `.git/config` не класть и не печатать. Pages пересоберутся сами.
- Сообщи Никите ссылку `https://kloserock97-tech.github.io/shelf/items/<slug>/`.
