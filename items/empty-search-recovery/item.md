- Товар — объект с `words` (слова названия, цвет, признаки), ценой и флагами. Слово запроса совпадает, если какое-то слово товара с него начинается; `jackets` сводится к `jacket`. Условия складываются через И.
- Ноль разбирается по шагам. Сначала незнакомые слова: слово, которого нет ни у одного товара, сравнивается со словарём каталога по расстоянию правки с перестановкой соседних букв (вставка, удаление, замена, обмен; порог 1 для слов до 4 букв, иначе 2; для недописанных слов — ещё и с началом слова той же длины). При равенстве побеждает слово, которое чаще встречается.
- Если после исправления выдача есть — одно предложение «Did you mean “rain jacket”? → 16». Если нет — ищется наименьший набор условий, которые вместе дают ноль: перебираются все подмножества по возрастанию размера, наборы из одних фильтров идут первыми. Этот набор пишется тегами («“rain jacket” + Under €40 + Waterproof match nothing together»), а чипы этих фильтров получают оранжевое кольцо.
- Ослабления — по одному шагу от исправленного запроса, каждое со своим числом: ближайшая ступень цены, после которой что-то есть («Up to €60»), снятие каждого фильтра, замена существительного из `swapWords` («Try “rain poncho”»), запрос без одного из слов. Если ни один шаг не помогает — пары фильтров, затем запрос без слов, затем без фильтров. Показываются до четырёх: сначала цена, затем снятие фильтров по убыванию числа. Если опечатка исправлялась, под подписью стоит «as “rain jacket”» и применение меняет текст в поле.
- «Nearest matches» — до шести товаров, которым не хватает меньше всего условий. Внутри берутся по очереди из групп «чего не хватает», чтобы в ленте были разные промахи, а в группе — по штрафу: 3 за несовпавшее слово, 1 за флаг, 1 + доля превышения за цену. Под ценой написан промах: «Not waterproof», «€8 over», «Not “jacket”». Если ноль дала только опечатка, лента называется «Results for “rain jacket”» и показывает то, что даст исправление.
- Применение: замер позиций всех карточек до и после, совпавшие по `id` едут с места на место (из ленты ближайших в сетку выдачи — со сдвигом и масштабом), новые проявляются снизу с шагом 28 мс, ушедшие гаснут на старом месте. Высота блока едет той же пружиной: свой затухающий осциллятор (ζ = 0,74, ω = 15), свёрнутый в `linear()`, 620 мс; без поддержки `linear()` — кубическая кривая.
- Ввод в поле пересчитывает выдачу через 160 мс после последней клавиши, Enter — сразу. Выдача идёт по возрастанию цены: до 8 карточек целиком, больше — первые 6 и кнопка «Show all N».
- Доступность: чипы — `aria-pressed`, ослабления — кнопки с именем «Remove Waterproof: 8 products», лента ближайших прокручивается с клавиатуры (`tabindex="0"`). `role="status"` объявляет «No products. 4 ways to widen the search.» и итог применения. После применения фокус возвращается в поле поиска, если кнопка, на которой он был, исчезла.
- `prefers-reduced-motion`: без перелётов и анимации высоты, новые карточки только проявляются.
- В покое ничего не считается: всё на событиях и Web Animations.
- Карточки без фото: цветная плитка и силуэт из своего SVG (куртка, флис, пончо, сапоги, брюки). `catalog.js` строит 60 товаров по сиду через хэш из `hash-kit`; водонепроницаемость добавляет к цене €12–19, поэтому непромокаемой куртки дешевле €40 в нём нет, а пончо и сапоги есть.
- Демо: стартует в нуле — «rain jacket», Under €40, Waterproof. `?shot=1` — то же состояние по центру экрана.
