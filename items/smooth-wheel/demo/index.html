Smooth wheel · λ = 6.5

Smooth the jolt, keep the distance

A mouse wheel moves a page in 100 px jumps. Here every jump is eased over about half a second, and the page still lands exactly where the browser would have put it.

01

The distance stays 1:1

One notch travels exactly as far as it would without any script. Changing the speed or direction of scrolling is what NN/g calls scrolljacking, and people take it for a broken page.

02

Only the jolt is smoothed

The position chases the target exponentially: 95% of the way in about 0.46 s. The step is measured in real time, so a slow device with rare frames takes the same half-second. Watch the graph: smooth decay with it on, sharp spikes with it off.

03

Trackpads keep their own inertia

Small pixel deltas mean a trackpad, which already glides. Smoothing it a second time would feel like rubber, so it scrolls natively. So do fingers.

04

Keys, scrollbar and find stay native

When something else moves the page (a key, the scrollbar, find-in-page, a script), the smoother drops its target and picks up the new place instead of pulling back.

05

Inner boxes go first

A scrolling box under the cursor scrolls natively until it reaches its end; only then does the page take over.
