- Отдельного тултипа нет. Над числом стоит дата, под ним разница с сегодняшним в деньгах и процентах. Отпустили — число возвращается к сегодняшнему, под ним прирост за период.
- Цифры — одометр.
  - У каждого разряда колонка 0–9, сдвиг `translateY(−d × 1,08em)`.
  - Переход 460 мс, каждый следующий разряд трогается на 16 мс позже.
  - При быстром скрабе CSS подхватывает переход с текущего места.
  - Если меняется длина числа или место запятой, колонки пересобираются без анимации. Края колонки мягкие, маска 16%.
- На графике пройденная часть синяя с заливкой 8%, остаток серый. Волосяная вертикаль и точка отмечают день, пунктир — уровень сегодняшнего значения.
- Ввод:
  - мышь и перо — наведением;
  - палец — долгим нажатием 320 мс, потом скольжением. Сдвиг больше 8 px до срабатывания считается прокруткой. Во время скраба `touchmove` гасится, страница не едет;
  - клавиатура — ←/→ по дню, с Shift по неделе, PageUp/PageDown по 30 дней, Home/End, Escape отпускает.
- Доступность: график — `role="slider"` с `aria-valuetext` вида «Wednesday, July 29, 2026: $44,821, −$2,046 (−4.4%) vs today». Цифры-одометр скрыты от скринридера, значение продублировано текстом. Минус — U+2212: смысл несёт знак, цвет его только дублирует.
- Работает только на ввод: не больше одной отрисовки за кадр, ResizeObserver перерисовывает, только если размер правда изменился.
- `prefers-reduced-motion`: цифры меняются сразу.
- Данные демо — год MRR из своего сидированного хэша (миксер Hash Kit). `?shot=1` — скраб, застывший на 29 июля.
