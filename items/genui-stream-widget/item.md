- Ответ модели — JSON вида `{ title, children: [{ type, ...props }] }`, приходит текстом кусками (`push(chunk)`, `end()`, `cut()`). После каждого куска (не чаще кадра) весь накопленный текст читает свой толерантный парсер: незакрытые строки, массивы и объекты берутся как есть, недописанное число, литерал или ключ ждёт следующего куска. Для каждого объекта и массива парсер помнит, закрыт ли он и какой ключ ещё дописывается, поэтому `"type":"sli` не считается типом.
- Реестр из шести своих компонентов: `text`, `slider`, `choice`, `stat`, `chart`, `button`. У каждого — скелет формы, условие готовности и монтаж. Блок с известным типом сразу показывает скелет (полоски с бегущим бликом), а когда пришли нужные поля (у ползунка — подпись, min, max, value; у выбора — подпись и первый закрытый вариант), становится настоящим контролом. Текст и заголовок растут по мере потока с курсором, варианты выбора добавляются по одному.
- Замена скелета на контрол идёт через `Element.startViewTransition` на слоте, если он есть, — остальной виджет при этом остаётся живым; иначе контрол проявляется через `@starting-style` за 280 мс.
- Готовые контролы работают во время потока: значения лежат в общем состоянии, тронутый человеком контрол поток больше не перезаписывает. `compute(state, blocks)` — код хоста, который считает числа для `stat` и `chart` (в демо — накопления по месячному взносу и ставке, которую прислала модель в вариантах счёта); `onAction(name, state)` — ответ кнопки.
- Обрыв (`cut()` или «Cut stream»): всё дошедшее остаётся рабочим, недописанный текст получает «…», начатые блоки без нужных полей превращаются в пунктирную плашку «The chart didn’t arrive», у неполных живых блоков — метка «cut off». Неизвестный тип пропускается с короткой пометкой.
- График — SVG из 24 столбцов, высота через `scaleY` с переходом 320 мс, пунктир цели, столбец месяца, когда цель достигнута, выделен; `role="img"` с итогом словами. Ползунок — нативный `range`, в `aria-valuetext` добавлен итог («goal in Oct 2027»), выбор — радиогруппа.
- Шапка показывает состояние (Streaming · %, Done, Cut off at %), поверхность виджета — `aria-busy` во время потока, итог объявляет `aria-live`. «JSON» показывает пришедший текст. В покое ничего не крутится: блик скелетов и мигание идут только во время потока, `prefers-reduced-motion` их убирает.
- `play(text, { seed })` — сценарный поток для демо: куски по 4–22 символа через 24–64 мс, изредка пауза 360 мс; случайность — генератор из Hash Kit. «Replay» проигрывает заново с другим зерном.
- Флаг демо: `?shot=1` — поток заморожен на 84%: четыре блока работают, у графика скелет; `&at=0.5` — любая другая точка.
