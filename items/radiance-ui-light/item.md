- Разметка задаёт сцену атрибутами: `data-rl-box` — карточка (заслон с освещённой гранью), `data-rl-text` — текст, который рисует свет, `data-rl-text="cast"` — он же заслоняет, `data-rl-emit` — цветной источник (`--rl-glow`, сила `--rl-power`), который сохраняет свой DOM-вид. Мелкий текст лучше не делать заслоном: в разрешении GI (0,5 px на css px) от него остаются пятна.
- При смене раскладки `dom-mask.js` рисует страницу дважды: цветом в полном разрешении и сценой GI (заслоны чёрным, источники цветом в линейном свете). `sdf-core.js` (общее ядро с `relief-icons` и `glow-dots-loader`) строит jump flooding'ом два поля: до заслона и до открытого пикселя. Каждый кадр идут только каскады и финальный проход.
- `radiance.js` — radiance cascades: каскад n — пробы через 2ⁿ px, 4ⁿ⁺¹ направлений, интервал [1,5·(4ⁿ − 1)/3, 1,5·(4ⁿ⁺¹ − 1)/3]. Лучи идут шагами по полю расстояний (12–64 шага по каскадам). Слияние сверху вниз с билинейной поправкой: луч ведётся к каждой из четырёх верхних проб, иначе на границах каскадов видны кольца. На окне 1200×900 — 6 каскадов по ~1 млн текселей.
- Лампа — полупрозрачный дисковый источник радиусом 7 css px и силой 2,6: она не отбрасывает тени и не участвует в поле расстояний, поэтому её движение не требует пересчёта поля. Затухание exp(−d/320 px) даёт пятно вместо ровной дымки.
- Финальный проход: альбедо × (фон + свет), кривая 1 − e^(−kx), дизер из `hash-kit`. Внутри карточки и буквы свет берётся у ближайшего открытого пикселя и гаснет вглубь (5 css px), плюс 45 % размытого света вокруг (mip 4). Грань загорается со стороны лампы.
- Ступени качества: 0,5 / 0,36 / 0,26 px GI на css px, на последней без билинейной поправки. Если медиана 40 интервалов кадров дольше 22 мс, ступень снижается, не больше двух раз. Для точного замера по времени видеокарты подходит `gpu-quality-governor`.
- Кадры идут, только пока лампа догоняет курсор (τ 70 мс). В покое, вне экрана и на скрытой вкладке ничего не считается. ResizeObserver пересобирает сцену, `refresh()` — вручную.
- Тема: тёмная — страница почти без фонового света, светлая — «бумага под лампой», фон 1,0 и экспозиция 1,6. Всё в переменных `--rl-*`.
- Доступность: текст и ссылки остаются в DOM (прозрачные, выделяются и читаются скринридером), canvas скрыт. Без WebGL2 — обычная страница. При `prefers-reduced-motion` лампа ставится сразу, без плавности. На касании лампа встаёт под палец.
- Грабли: ANGLE на D3D11 неверно считает функцию с циклом марша, если её вызвать в цикле по четырём пробам. Вызовы расписаны вручную.
- `data-theme="dark"` на корне оставляет тёмный вид и на светлой странице.
- Демо: переключатель Warm / Cool / Off, слева внизу ступень качества и мс. `?shot=1` — лампа у правого края заголовка, неподвижный кадр; `?theme=dark` — тёмный вид (постер снят с ним).
