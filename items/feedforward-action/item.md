- Три вида действий задаются атрибутами кнопки: `data-ffa="archive"` (строки с `data-status` = `data-match`), `"sort"` (по `data-<key>` по возрастанию), `"style"` (класс `data-class` на подходящие строки). Тексты — `data-preview`, `data-done`, `data-noop` с подстановками `{n}`, `{names}`, `{moves}`, `{total}`. Счётчик в подписи (`data-n`) пересчитывается после каждого действия; действие без цели получает `aria-disabled`.
- Превью: архив — строки гаснут до 0,38 и зачёркиваются линией слева направо (320 мс, шаг 45 мс); сортировка — SVG-дуги от каждой переезжающей строки к её новому месту, изгиб растёт с дальностью (16 + 7 px на строку, не больше 48), линия прорисовывается за 380 мс; стиль — пунктирный красный контур и лёгкая заливка поверх строк. Строка статуса пишет, что именно случится.
- Нажатие делает призрак настоящим: зачёркнутые строки уезжают вправо, остальные подтягиваются FLIP-пружиной; при сортировке строки едут по месту стрелок; стиль из пунктира становится сплошным с полосой слева. Подтверждений нет, вместо них Undo, история на все шаги.
- Ввод: мышь — превью через 90 мс наведения (между кнопками без задержки), уход отменяет; клавиатура — превью на фокусе, Enter/Space применяет, Esc отменяет; касание — удержание 260 мс показывает превью, отпускание на кнопке применяет, увод пальца дальше 16 px от кнопки гасит призрак до 0,35 и пишет «Release to cancel», короткий тап применяет сразу.
- Скринридер: описание результата висит на кнопке через `aria-describedby`, итог и «Undo is available» объявляет `role="status"`; превью по наведению в живую область не пишется.
- `prefers-reduced-motion`: без пружин, зачёркивания и прорисовки, только смена прозрачности.
- Демо: `?shot=1` — просроченные уже подсвечены, в превью сортировка со стрелками; `?shot=archive` — превью архива.
