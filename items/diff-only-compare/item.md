- Разметка — обычная таблица: `<th scope="col">` у вариантов, `<th scope="row">` у подписей, `<caption>` для скринридера. Строки разделов (`.dfc-section`) — `<th colspan scope="colgroup">`.
- Сравнение строк:
  - по `data-v` у ячейки, если он есть, иначе по тексту;
  - строка, где все значения совпали, получает `.is-same`; раздел — тоже, если под ним нет ни одной различающейся строки;
  - `data-better="higher|lower"` у строки включает метки: лучшему значению — зелёная плашка «↑ Best» и зелёный текст, худшему — красная стрелка вниз. При равенстве метку получают все совпавшие. Строки без направления (передачи, подножка) меток не получают.
- Схлопывание: скрипт оборачивает содержимое каждой ячейки в `.dfc-fold > .dfc-clip > .dfc-pad`. Тумблер ставит `.is-diff`, и у одинаковых строк `grid-template-rows` едет `1fr → 0fr` вместе с паддингом, прозрачность до 0, нижняя граница до 0 px — 340 мс. По окончании строки получают `hidden` и уходят из дерева доступности. Обратно — `hidden` снимается, затем класс, строки раскрываются.
  - `.dfc-clip` режет через `overflow: clip`, а не `hidden`: так он не становится скролл-контейнером и подпись раздела внутри остаётся липкой.
- Прокрутка: `.dfc-scroll` держит обе оси (`max-height` через `--dfc-max-h`), поэтому шапка липнет к верху, а колонка подписей — к левому краю одного и того же контейнера. Угол шапки липнет к обоим.
- Шапка в чипы: при прокрутке вниз больше 8 px подпись варианта сворачивается, имя уходит в капсулу, отступы уменьшаются (240 мс). Обратно — только на `scrollTop` 0, и только если запас прокрутки больше 48 px: шапка при сжатии становится ниже, и без этого запаса прокрутка обрезалась бы до 0 и шапка мигала бы.
- Узкий контейнер (container query до 520 px): колонка подписей 104 px, колонки вариантов `max(124px, (ширина − 104) / 1,65)` — видно полторы колонки, лента листается с `scroll-snap-type: x mandatory` и `scroll-padding-left` под колонку подписей.
- Доступность: тумблер — `<input type="checkbox" role="switch">` внутри `<label>`; `role="status"` объявляет «8 identical rows hidden»; у меток есть текст для скринридера («Best», «worst»); область прокрутки — `role="region"` с `tabindex="0"` для стрелок.
- `prefers-reduced-motion`: одинаковые строки гаснут за 160 мс и затем убираются разом, без схлопывания по высоте; шапка и тумблер без анимации.
- Демо: `?shot=1` — режим различий включён, таблица прокручена на 40 px, шапка в виде чипов.
