- Картинка во время перехода — буфер с обратной связью: две текстуры RGBA8 по очереди (ping-pong), каждый кадр строится из предыдущего. Экраны — функции `paint(ctx, w, h)` в CSS px, рисуются в Canvas 2D в разрешении устройства (DPR до 2).
- P-кадр: у каждого блока 16×16 css px один вектор, все пиксели блока берутся из прошлого кадра со сдвигом на него. Вектор = смещение жеста × (0,55…1,45 по хэшу блока) + вихрь из нашего value-шума по координатам блоков + наклон яркости нового экрана вокруг блока. Последний тянет старые пиксели вдоль краёв нового макета. 18% блоков кодируются «без движения».
- Векторы округляются до целых пикселей, выборка `texelFetch`: копирование без потерь, мазки не мылятся. P-кадры идут ровно 60 в секунду при любой частоте экрана. Зерно векторов меняется раз в 7 шагов, поэтому соседние кадры движутся согласованно и пиксели текут полосами, а не дрожат.
- Новый экран просачивается слабым остатком (1,5% за шаг в половине блоков) и редкими блоками целиком (1,2% за шаг), как внутрикадровые блоки в P-кадре.
- Ключевой кадр: новый экран встаёт блоками в порядке развёртки, сверху вниз, за 0,2 с. Тянешь — течёт: сдвиг пальца за кадр (до 26 px) задаёт вектор. Если держать неподвижно, пиксели медленно плывут в последнем направлении. Отпустил — ключевой кадр. Дольше 3,5 с он приходит сам, как конец группы кадров. Касание без сдвига и кнопка запускают авто: 0,65 с потока по синусоиде, затем ключевой кадр.
- Отличие от `glitch-bands`: там каждый кадр — отдельная постобработка поверх готовой картинки (сдвиг полос, разъезд каналов), и смена картинки прячется в пике. Здесь у кадра есть память: каждый следующий строится из предыдущего, и ошибка накапливается до ключевого кадра.
- Цикл идёт только во время перехода. Вне экрана и на скрытой вкладке — пауза, при смене размера экраны перерисовываются. `prefers-reduced-motion`: вместо потока растворение за 0,25 с.
- Доступность: холст `aria-hidden`, обёртка `role="img"` с названием текущего экрана, смена объявляется через `aria-live`. Кнопка «Next screen» — то же, что жест. Без WebGL2 экраны просто сменяются.
- На холсте `touch-action: none`: палец на сцене ведёт переход, а не прокручивает страницу.
- Демо: `?shot=1` — середина перехода: 18 P-кадров со сдвигом (7; 2,5) px, без подписи и кнопки; `&n=30` — другое число P-кадров.
