# Shelf — спецификация

Версия 1, 2026-09-28. Исследование аналогов и опись кандидатов лежат локально в `docs/research/` (вне git).

## Зачем

Личная полка UI-решений Никиты: компоненты, кнопки, секции и страницы, мини-приложения, WebGL- и Three.js-сцены,
шейдеры, интерфейсные анимации, загрузчики. У каждого элемента живое превью и код в одном или нескольких вариантах.
Полкой пользуются Никита и Claude, когда придумывают интерфейсы: найти приём, посмотреть его вживую, забрать код
или промпт.

Репозиторий публичный только ради хостинга на GitHub Pages. Сайт нигде не продвигается: на всех страницах и во всех
демо стоит `noindex, nofollow`, у репозитория нет topics.

## Решения

| Вопрос | Решение |
| --- | --- |
| Имя | Shelf |
| Стек | Astro 7, статическая сборка, GitHub Pages через Actions |
| Дизайн | дизайн-система Shelf (артефакт Design System); токены — `design/tokens.json` → `src/styles/tokens.css` |
| Шрифты и иконки | Onest, JetBrains Mono (OFL, через Fontsource); Lucide (ISC). SF Pro и SF Symbols на вебе запрещены лицензией |
| Язык | интерфейс на английском и русском (`/shelf/` и `/shelf/ru/`, выбор в меню профиля и в ⌘K, запоминается); заметки к элементам по-русски |
| Кто добавляет | Claude по просьбе Никиты (скилл `shelf-add`); вручную — `npm run new` |
| Приватное | `private/<slug>/` не попадает в git; локально видно с бейджем Private |
| Чужое | `origin: third-party` в публичную папку не проходит проверку; `adapted` требует `priorArt` |
| Лицензия | PolyForm Noncommercial 1.0.0, как у остальных публичных демо |

## Элемент

Папка `items/<slug>/`:

- `item.md` — метаданные во frontmatter (схема — `src/content.config.ts`) и заметки в теле: грабли, решения, где используется.
- `demo/index.html` — живое превью. Подключает файлы варианта через `../variants/<id>/…`, фон прозрачный. У внешних
  проектов вместо папки — `demo.url` на их страницу.
- `variants/<id>/` — код варианта: `html`, `react`, `vue`, `three`, `r3f`, `webgpu`… Порядок файлов задаёт `files`.
- `poster.webp` — кадр 4:3 (`npm run capture`), `loop.mp4` — необязательный ролик для наведения.

Типы (18, в четырёх группах сайдбара): button, control, card, navigation, gallery · scroll, cursor, text, transition,
loader · webgl, shader, object, background, icon · section, sound, utility. Старые адреса `/type/component/`,
`/type/motion/` и `/type/app/` ведут на `control`, `gallery` и `webgl`.
Статусы: stable, draft.

`platform` — `web` (по умолчанию), `mobile` (паттерн телефонного приложения) или оба. Переключатель «Все / Веб / Мобайл»
в тулбаре списка, как платформы в Mobbin: режим запоминается и переходит со списка на список; мобильные элементы
открываются на сцене и в «Живом демо» в ширине телефона, постер снимается в рамке телефона (`capture` сам или `--phone`).

Второй слой — `src/lib/curation.ts` (id повторены в `scripts/lib/items.mjs` для проверки):

- `jobs` — какую задачу элемент решает для человека на странице (16: navigation, discovery, showcase, storytelling,
  first-impression, atmosphere, feedback, loading, comparison, contact, input, onboarding, empty-state, error, data,
  quality), главная первой. Тип говорит, что это; задача — зачем.
- `collections` — подборки вкуса: feels-expensive, calm, depth, no-assets, retro, playful.
- `usedIn` — проекты, где элемент работает вживую (ts2, windcrest, driftfield, nightsail, meadow-walk), со ссылкой на
  живой сайт.
- `pairs` — «хорошо сочетается»: собраны на одном экране или один использует другой; хватает одной стороны.
  `related` — закрепить похожий первым; остальные похожие считаются (`src/lib/similar.ts`).

## Интерфейс

Правила вида и поведения — `docs/STYLE-GUIDE.md`. Промпт для генерации экранов в этом стиле —
`docs/CLAUDE-DESIGN-PROMPT.md`.

- Сайдбар: Search (палитра), All items, Favorites, Coverage, 18 типов в четырёх сворачиваемых группах (Interface, Animation,
  Graphics, Pages & tools), подборки (Collections), профиль с меню (язык, тема, вид Floating / Attached, горячие клавиши). Знак анимирован
  при первом заходе за сессию. ⌘B / Ctrl B или кнопка со стрелкой сворачивают его в колонку иконок с тултипами;
  верхняя иконка колонки — та же кнопка, она и разворачивает. Край тянется от 216 до 320px, на телефоне — лист.
  Состояние живёт в localStorage.
- Библиотека: витрина с одним элементом крупно, под ней полка подборок (мозаики из трёх обложек, стрелки, прилипание), дальше группы полками — ряд на группу, как в App Store (или сеткой постеров 4:3); «Все элементы» разбиты на разделы по группам
  типов. Тулбар прозрачный, пока под ним нет контента. Первая строка: масштаб сетки, меню «Вид»: полки или сетка, группировка (разделы, задачи, без групп) и порядок (By kind,
  Newest, Recently updated, A–Z; при поиске — Best match). Вторая строка — поле «Искать среди N» и фильтры по мотивам
  Mobbin:
  - фасеты Type, Task (задача), Stack, Tags с поповером; в поповере поиск, группы и счётчики против остальных фильтров;
  - ИЛИ внутри фасета, И между фасетами;
  - быстрые чипы стека;
  - адрес вида `?type=…&job=…&stack=…&tag=…&view=…&group=…&sort=…`;
  - ссылки сайдбара уносят Task, Stack, Tags и порядки Recently updated / A–Z;
  - нулевой результат предлагает, какой фильтр снять;
  - на телефоне — нижний лист.
  Логика — `src/scripts/library.ts`, определения — `src/lib/facets.ts`. У страницы типа и подборки — веер обложек
  и строка о них. Пустые состояния с линейными иллюстрациями. Ролик играет по наведению через 300 мс, кроме reduced motion и
  Save-Data. Кнопка «Живое демо» на карточке открывает работающее демо поверх списка (Quick Look).
- Страница элемента: хлебные крошки, которые помнят, откуда пришли (список с фильтрами и прокруткой), сцена с живым
  демо в iframe (ширина экрана, фон и сетка для локальных демо, перезапуск, полный экран), код по вариантам и файлам
  (Copy, Download, Copy prompt), команда установки из реестра, заметки, паспорт (задача, где используется со ссылкой
  на живой проект, подборки, источник — поле `source`), «Хорошо сочетается» и «Похожие». Открытый из подборки
  элемент держит её выделенной в сайдбаре и в крошках.
- Покрытие (`/coverage/`): сколько элементов под каждую задачу и каждый тип, слепые пятна (задачи без элементов),
  «пока по одному» и «что искать дальше» — одно слепое пятно в неделю.
- Иконки сайта — `npm run icons` из знака: favicon.svg/.ico, apple-touch-icon, 192/512 и маскируемая 512, манифест.
- ⌘K / Ctrl K — поиск по мотивам Mobbin: тёмное окно, недавние выборы чипами, вкладки Новое / Типы / Задачи /
  Подборки / Стек и теги с плитками обложек, а по словам — «Лучшее» (показать всё, элементы, фильтры, разделы, действия).
  У элемента под мышью или стрелками — карточка-подсказка с петлёй или постером и описанием. `/` — поиск по списку, R — случайный элемент, `?` — список клавиш. В сетке стрелки,
  Space — живое демо (Quick Look), F — избранное, `[` `]` — масштаб. На странице элемента C — код, P — промпт, F — избранное,
  1–4 — вариант кода.
- Избранное, недавние, тема, масштаб и выбранный вариант кода живут в localStorage этого браузера.
- Живой WebGL — только на странице элемента и в Quick Look; iframe удаляется при закрытии, контекст освобождается.
- Поисковый индекс: списки несут его прямо в странице (фильтрам он нужен до первой отрисовки), страницы элементов
  грузят общий `/search-index.json` (`/ru/search-index.json`) с preload — браузер берёт его из кэша от страницы к
  странице. Встроенным он был до трети веса страницы элемента.

## Сборка и проверки

- `npm run check` — поля, файлы, правила происхождения, утечки (адреса закрытых систем, ключи, токены) и отпечатки
  чужого кода в публичных элементах (`scripts/lib/provenance.mjs`: известные хэши, шумы, тонмапперы, FXAA, CAS,
  классика Shadertoy, GSAP, LYGIA). Свои замены — элементы Hash Kit и Edge AA.
- Лицензии того, что уходит в браузер (MiniSearch, значки Lucide, шрифты Onest и JetBrains Mono, рантайм Astro), сборка
  пишет в `public/THIRD_PARTY_NOTICES.txt`; ссылка — в меню профиля.
- `npm run build` — раскладывает демо и медиа в `public/`, собирает реестр shadcn в `public/r/`, строит сайт.
- `npm run smoke` — сайт в Chrome: ошибки консоли, горизонтальная прокрутка, палитра, поиск, Quick Look,
  копирование, вариант кода, фон сцены, сайдбар, язык и ссылка пропуска, телефон; английские и русские страницы.
- `npm run capture -- <slug>` снимает локальное демо через временный http-сервер (ES-модули с file:// не грузятся);
  `--query "?p=0.4"` передаёт демо параметры.
- Деплой — push в `main`; workflow гоняет check и build.
