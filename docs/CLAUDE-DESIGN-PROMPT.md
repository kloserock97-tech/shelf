# Промпт: три экрана Shelf

Готовый промпт для Claude (claude.ai, Claude Design или Claude Code с фронтенд-скиллом). Скопируй всё, что ниже
линии. Правила взяты из `docs/STYLE-GUIDE.md`, значения — из `design/tokens.json`. Если они разошлись, прав
`tokens.json`.

---

Ты senior product designer. Сделай три экрана веб-приложения **Shelf** — личной полки UI-решений дизайнера.
На полке лежат компоненты, кнопки, WebGL- и Three.js-сцены, шейдеры, анимации и загрузчики. У каждого элемента есть
живое превью и код в нескольких вариантах: HTML/CSS, React, Vue, R3F. Полкой пользуются, когда придумывают
интерфейс: найти приём, посмотреть вживую, забрать код.

Стиль — тихий интерфейс в духе приложений Apple (Music, Finder в macOS 26–27) с деталями ChatGPT. Хром нейтральный,
вся выразительность отдана превью.

## Формат

- Каждый экран — отдельный самодостаточный HTML-файл 1440×900. Стили внутри файла.
- Шрифты — Onest и JetBrains Mono с Google Fonts. Иконки — Lucide: обводка 1.75, скруглённые концы, `currentColor`.
- Превью элементов нарисуй сам: CSS-градиенты, SVG или `<canvas>`. Не бери стоковые картинки и не делай серые
  заглушки. Превью должны выглядеть как настоящие работы: травяной холм на закате, облако светящихся частиц,
  ночное море с лучом света, стеклянная кнопка, пружинящий переключатель.
- Все цвета, радиусы и тени — через CSS-переменные ниже. Не вводи новых значений.

## Общий каркас

### Сайдбар

Ширина 248px. Плавающая панель в 8px от краёв окна:

- радиус 16, фон `--sidebar` + `backdrop-filter: var(--blur)`;
- тень `var(--shadow-panel), inset 0 0 0 .5px var(--glass-edge), inset 0 1px 0 var(--glass-edge)`.

Сверху вниз:

1. **Шапка 52px.** Знак 28×28 на `--accent`, радиус 8: четыре белых скруглённых бруска, как полка с предметами.
   Рядом «Shelf» 17/22 w700 −0.02em. Справа круглая кнопка 28px с иконкой `panel-left` цветом `--label-secondary`.
2. **Группа без заголовка.** Search с клавишей ⌘K справа (видна при наведении), All items 90, Favorites 11.
3. **Группы типов**, у каждой заголовок 28px и шеврон при наведении:
   - Interface: Components 17, Buttons 4, Cards 5, Navigation 3, Galleries 8;
   - Animation: Motion 6, Scroll effects 4, Text effects 3, Loaders 2;
   - Graphics: 3D & WebGL 12, Shaders 9.
   Иконки: `component`, `mouse-pointer-click`, `square-stack`, `compass`, `gallery-horizontal-end`, `orbit`, `mouse`,
   `type`, `loader`, `box`, `blend`.
4. **Подвал.** Сверху линия 0.5px `--separator`. Кнопка профиля 44px: аватар 28px на `--inverse` с буквой N,
   «Nikita Gorbachev» 13/18 w600, «90 items on the shelf» 12/16 `--label-secondary`, справа `chevrons-up-down`.

Строка сайдбара:

- 36px, внутренние отступы 0 10 0 15, зазор 12, радиус 8, иконка 18px `--label-secondary`;
- счётчик 12/16 справа, `--label-secondary`;
- текущая строка: пилюля `--fill-selected`, подпись w600, иконка `--accent-text` — единственная цветная иконка
  в сайдбаре;
- наведение: `--fill-subtle`, тише выбора;
- строки идут через 1px, группы через 16px.

### Тулбар

52px, липкий, отступы 0 20. Наверху страницы он прозрачный и без линии. Когда под ним есть контент, у него фон
`--bar` + размытие и линия 0.5px снизу.

Не больше трёх групп:

- заголовок со счётчиком и ряд чипов;
- поле фильтра;
- масштаб сетки и сортировка.

## Нельзя

- Больше одного цвета акцента; градиенты и свечения в интерфейсе (в превью — можно); цветные тени.
- Рамки вокруг карточек, групп и панелей. Внутри панелей — только линии 0.5px.
- Тени у элементов в покое: у карточек, чипов, строк, тулбара.
- Стекло на карточках, коде и листах: палитра и меню непрозрачные.
- Иконки в цветных кружках-подложках, эмодзи, иллюстрации-маскоты, «Welcome back», карточки-метрики с процентами.
- Цветные иконки в сайдбаре, кроме иконки текущего пункта.
- Капс, восклицательные знаки, «Click here», «Submit».
- Inter, SF Pro, системный шрифт вместо Onest.
- Воздух внутри строк вместо воздуха между группами. Это рабочий инструмент: строки 36px, контролы 28–32px.

## Проверь перед сдачей

1. Если закрыть превью серым, экран почти чёрно-белый. Весь цвет даёт контент.
2. На каждом экране одна синяя кнопка и одна синяя иконка в сайдбаре.
3. Радиусы концентричны: сайдбар 16 = строка 8 + отступ 8; дорожка сегмента 10 = бегунок 8 + отступ 2.
4. Все подписи интерфейса по-английски, в sentence case. Заметки к элементу — по-русски.
5. Тёмная тема — не инверсия светлой: фон чисто чёрный, поверхности меню и палитры #2C2C2E, акцент текста #2997FF.
